# Rise of the Oblivion

Demo de un metroidvania 2D en pixel art, desarrollada en Python con pygame-ce
sin motor de juego: bucle principal, físicas, colisiones y animaciones
implementadas desde cero.

> 🚧 **Estado:** en desarrollo

## Características


## Tecnologías

- Python 3
- pygame-ce
- Aseprite (edición de sprites y animaciones)

## Cómo ejecutarlo

```bash
git clone https://github.com/diegosangodoy2002/evil-engine.git
cd evil-engine
pip install pygame-ce
python main.py
```

## Qué he aprendido

- Cómo funciona un game loop y el uso de delta time

## Créditos

Sprites generados con asistencia de IA (PixelLab) y editados a mano en Aseprite.
